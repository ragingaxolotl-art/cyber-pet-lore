# First prose critique

This is an editorial self-review of the completed first manuscript, not an independent reader test.

## Findings

The mystery is distinct from hidden-person stories and has a fair explanation: the saved state predates a relationship. But the verifier has no memorable behavior, and the false lead is dispatched too fast. The third and fourth chapters read like test reports.

## Required second pass

Give the verifier an attachment to the predictability of successful returns, shown in action. Make the incorrect interface diagnosis costly without making it foolish. Add a brief translated exchange at the decisive proposal. Follow the final observation through sensory changes and interrupted expectations.

## Collection comparison

All five first drafts are too uniformly procedural despite their different plots. The second pass must add substantial scene material, distinctive sensory language, bounded exchanges and immediate consequences. Avoid adding exposition about personhood to manufacture emotion. Let recurrence, interruption, dependency and costly action carry it. Preserve all five different resolutions.
