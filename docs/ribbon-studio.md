# Ribbon studio — October 30, 2026

The Atlas ribbon archive now links to `site/ribbons/studio/`: a local canvas composer with 40 interchangeable pieces (24 new PixelLab designs and 16 existing archive components). Includes ten ribbon bodies, ten medals, four rosette heads, four tails/trims and twelve clasps. Seven metal-color presets supplement the full color picker. Whole-layer and sampled hue-family recoloring preserve alpha and shading; original source PNGs remain unchanged during editing. Hue-family mode is not semantic material detection.

Users can select, drag, resize, reorder, duplicate, hide and remove layers; undo/redo; save a browser draft; download transparent 512×640 PNGs; and copy/import/download RBN1 recipe codes. Codes preserve colors, source hue, tolerance, coordinates and layer order. Decode validates library, limits, part IDs and checksum before applying; a failed import leaves the design intact. `site/ribbons/studio/README.md` documents the portable recipe format.

Artwork provenance, repairs and final replacement IDs are recorded in generation-record.json and catalog.json. Two rejected ribbon generations contained unwanted partial dragons; these were replaced before publication. The clean Moon silk also uses exact PixelLab workbench editing to remove unwanted footwear and restore its lower fitting. Final gallery entry: 4646c6ea-df7f-442e-b46d-11420a5236aa. Rejected originals remain under sources/ribbon-studio-originals on the SSD, not in the published cabinet. No existing award requirements or saves change.

Verification: Node tests cover all part-code round trips, Unicode, corrupted/invalid codes, color isolation, transparency, shading and preset bounds. Browser checks cover adding/selecting layers, recoloring, picking an original fabric color, duplicate/undo, exact code restore, transparent PNG download, and a narrow layout without horizontal overflow. All 40 final parts were visually reviewed. Existing archive PNGs retain original hashes. See sources/ribbon-studio-publication for deployment evidence.
