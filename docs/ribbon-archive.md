# Ribbon archive

`site/ribbons/` is the complete single-page reference saved October 28, 2026.
It contains 160 cards: 96 published main-game awards, 10 published battle honours,
42 unassigned PixelLab library designs, nine Foundling concept/master images,
and three active Foundling placements (medal, miniature medal, scroll).
The mini medal shares the approved artwork; it is not a separate achievement.

Each card records definition, placement, reward, animation, use status and source.
Unused designs have no invented gameplay criteria or reward. Static concept names
are descriptive working labels. Character browsing remains undecorated.

The full 80-piece PixelLab reserve library is preserved: 38 are assigned to the
main game/battle, 42 remain unassigned. The nine archived Foundling source designs
were downloaded from their recorded PixelLab gallery IDs. The approved 56-frame
atlas, nine scroll frames and animation recipe are preserved byte-for-byte.
No signed expiring download URLs, student media or saves are included.

Definitions use CPP-V3's published Foundling release award catalog and the current
public battle achievements.js. Legacy source credit remains in CPP-V3's asset
manifest; no new licensing claims are made. `directory.json` records file hashes,
PixelLab IDs and known provenance. `field-guide.txt` is a readable complete copy.
`ribbon-archive.zip` includes the page, catalog, descriptions and original assets.

Animation previews use the actual frame grids, respect Reduced Motion, have a
manual pause control, and update only visible canvases. Trophy atlases use the
same 80px cell and base-overlay rules as the game. The static HTML keeps every
card available without JavaScript; animation-specific cards include original
asset downloads. Filters are optional, not pagination.

For updates, preserve stable card IDs and archive artwork; update directory.json,
static cards and field-guide.txt together, then regenerate the ZIP. Do not change
award requirements from this page; runtime catalogs own gameplay definitions.
